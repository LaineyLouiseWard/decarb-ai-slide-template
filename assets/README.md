# Brand assets

These files are **not tracked in git** — they are official Decarb-AI branding
and are not redistributable. Drop them into this folder before compiling.

Required files:

| File | What it is |
|------|------------|
| `bg-title.png` | Title-slide frame: white left panel, transparent photo-hole, swoosh |
| `bar-bottom.png` | Bottom swoosh (content slides) |
| `logos-strip.png` | Funder logo strip (Decarb AI · Innovate for Ireland · AIB · Research Ireland) |
| `photo-1.jpg` | Default title-slide cover photo (any 3:2 photo works) |

Source: the official Decarb-AI branding pack (PowerPoint template + logo pack).
The PNGs above were exported from that pack. Use them only for Decarb-AI work.
